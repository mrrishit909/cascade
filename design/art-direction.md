# Art direction

## Concept: microscopic cyber-luxury

1. **Chosen - Precision instrument.** Thin 1px violet-line borders, graphite panels, compact monospace data tables, sharp corners but refined spacing (not heavy brutalist weight). Reference: semiconductor fab dashboards and precision-measurement tools.
2. Rejected - "Hacker terminal green-on-black": too generic sci-fi, doesn't differentiate from a hundred other dark dashboards, and the book's palette (violet/iridescent/copper/photoresist-pink) explicitly isn't green.
3. Rejected - "Heavy brutalism" (RIFT's register): rejected specifically to keep this project from reading like a reskin of blueprint 01 in the same volume.

## Palette (from the blueprint, used verbatim)
Graphite `#08090B`, Silicon `#161A20`, Wafer Violet `#7457FF`, Iridescent `#5EF1D2`, Copper `#D98042`, Photoresist `#FF46A2`, Cleanroom `#E9F4FA`.

## Typography
System sans at a smaller base size (14px vs RIFT's 15px/AURELIA's 15px) for a denser, more technical feel; `ui-monospace` for every cell/die table value.

## Component grammar
1px hairline borders (not RIFT's heavy 2px brutalist lines, not AURELIA's soft glow), no border-radius anywhere, compact padding. The three projects in this volume so far are visually unmistakable from each other at a glance.
